# 江湖多情债 · 本地与 iPhone 试玩

这个文件夹已包含完整游戏、人物、地图、战斗与离线功能。游戏不使用 GPT 账号，也不请求 GPT API。存档保存在当前浏览器，可从游戏「存档」导入、导出 JSON。

## 在自己电脑启动

先安装 Python 3（https://www.python.org/downloads/）。Windows 安装时勾选 **Add Python to PATH**。

- Windows：双击 `start-game.bat`。
- Mac：双击 `start-game.command`；如系统阻止打开，可在终端进入这个文件夹，运行 `python3 start_game.py`。
- 其他系统：在这个文件夹运行 `python3 start_game.py`。

启动窗口会显示两个地址。电脑打开 `http://127.0.0.1:8765/`；iPhone 请用 Safari 输入窗口里显示的局域网地址，例如 `http://192.168.1.20:8765/`。示例地址不是固定地址，以自己窗口显示的地址为准。

电脑和 iPhone 必须连接同一 Wi-Fi，并保持启动窗口开启。如有防火墙提示，仅允许家庭/专用网络；无需打开路由器端口或暴露公网。访客 Wi-Fi、手机蜂窝网络或开启设备隔离的网络可能无法访问电脑，换成同一个普通家庭 Wi-Fi。

如果端口被占用，运行 `python3 start_game.py --port 8766`，并使用显示的新地址。按 Ctrl+C 停止服务。

## iPhone 离线安装

局域网的 HTTP 地址可以直接游玩，但 iPhone 浏览器只允许在 HTTPS（或手机自身 localhost）环境安装 Service Worker，所以不要在这个局域网 HTTP 地址上期待离线下载成功。

需要主屏幕离线单机版时，用 Safari 打开云端 **HTTPS** 试玩地址，点击「单机」→「下载离线单机版」，等到显示「离线版已备好」，再点 Safari「分享」→「添加到主屏幕」。之后可以断网启动。云端地址见仓库的主 README。

## 保留旧进度

换网址、浏览器、局域网 IP 或端口时，浏览器不会自动共享存档。先在旧游戏的「存档」导出 JSON，再到新地址导入。不要清除浏览器网站数据，否则可能删除本地存档与离线内容。

地图上点道路走路，靠近人物点「互动」；屋内靠近家具点「查看」。秘籍须在行囊研读，才能加入实际战斗技能。
